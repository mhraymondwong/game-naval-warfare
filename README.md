# 海戰風雲錄

原創的 3D 海戰小原型（Godot 4.7，Forward Plus，1280×720）。船型、地圖與介面都是本專案原創，不是任何既有遊戲的複刻。

## 如何開啟

1. 安裝 [Godot 4](https://godotengine.org/)（建議 4.7）。
2. 用 Godot 開啟本資料夾的 `project.godot`，按 F5。

## 玩法

- 你指揮戰艦「海風」（3000 HP，四座三聯裝主砲），對手是 4 艘巡洋艦和 6 艘驅逐艦，共 10 艘。
- 鏡頭在艦後上方。海面有湧浪、反光和浪花，島嶼可以擋路。
- 敵艦會巡航，你進入牠們的艦首射界就會開火。
- 擊沉全部 10 艘就勝利；海風沉沒時可以按「再來一次」。

## 操作

畫面採用類搖桿／手把圖示操控（滑鼠或觸控），**沒有文字按鈕**。鍵盤仍可全程使用，且螢幕控件會跟著亮起／移動。

### 左下｜虛擬舵機（油門＋舵）

圓形底座＋可拖曳旋鈕，僅圖示箭頭，無文字。

| 方向 | 效果 |
|---|---|
| 上／下 | **油門指令**（前進／後退）。採「船用車鐘」：放開旋鈕後**油門維持**在放開時的檔位 |
| 左／右 | **舵角**。放開後舵自動回正 |
| 點擊中心附近 | 油門歸零（死區） |

### 右下｜開火／砲塔群

| 控件 | 效果 |
|---|---|
| 中央大火鍵（準星／砲彈圖示） | 開火；外圈顯示裝填進度 |
| 兩側小圓鍵（彎箭頭） | 按住轉動砲塔 |
| 上方小羅盤 | 目前砲向 |

### 鍵盤（仍可用）

| 動作 | 鍵 |
|---|---|
| 油門前進／後退（同樣寫入車鐘，放開後維持） | W／S |
| 左轉／右轉（暫時舵） | A／D |
| 砲塔左轉／右轉 | Q／E |
| 開火 | 空白鍵 |

### 左側艦橋 HUD

窄幅半透明鋼／玻璃儀表面板（黃銅飾邊）：艦名與剪影、分段艦體耐久、圓形航速表、砲向羅盤、巡洋／驅逐剩餘圖示。右上角小地圖：黃點是你，紅點是敵艦。

## 檔案

- `scenes/battle.tscn`：主場景
- `scripts/battle.gd`：船艦模型、操控、敵艦、射擊和 HUD 組裝
- `scripts/virtual_pad.gd`：虛擬舵機
- `scripts/fire_pad.gd`：開火／砲塔群
- `scripts/naval_panel.gd`：左側專業 HUD
- `scripts/minimap.gd`：小地圖
- `scripts/test_controls.gd`：無頭操控煙霧測試
- `shaders/sea.gdshader`：海面
